# Regina-portfolio

Portfolio de Régine Occansey — Administratrice Systèmes & Réseaux, construit avec Next.js (App Router) et Framer Motion.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm start` — sert le build de production
